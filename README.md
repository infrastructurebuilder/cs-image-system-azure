# cs-image-system-azure

cs-image-system plugins (or aggregator) for Azure

This is initially the location for Azure-specific plugins and aggregator functionality within the cs-image-system project.  It may later just become an aggregator if the individual plugins are moved to independent repositories.

This depends on `cs-image-system-contract` for the core interfaces and contracts that the Azure-specific plugins and aggregator functionality implement.

## Structure

- `packages/` - Contains Azure-specific plugin implementations.
